# Contributing

Thanks for taking a look at this learning project.

## Before making a change

1. Keep functions small and use descriptive names.
2. Validate inputs at the function boundary.
3. Add or update tests for behavior changes.
4. Run `results = runtests('test_controller_step.m')` and confirm the tests pass.
5. Run `generate_test_report` if you want a fresh CSV test report.
6. Explain the purpose and validation of your change in the commit message.

## Scope

Keep changes focused on the simplified educational model. Do not use this repository to control real equipment.
